## 단계별 세부 WBS

### 1단계 — 기획
- 독거노인 안심케어 문제 정의
- 어르신/보호자 시나리오 작성
- 기능 범위(MVP) 확정

### 2단계 — 기반 구축
- `flutter_app` 생성, 테마/폰트(큰 UI) 적용
- `backend` Spring Boot 프로젝트, PostgreSQL 연동
- 기본 헬스체크 API

### 3단계 — 인증·역할
- 역할 선택 화면
- 어르신/보호자 로그인·회원가입
- 로그인 상태 유지 및 홈 분기

### 4단계 — 어르신 기능
- 홈/메인 화면
- AI 채팅 화면 및 API/Mock 연동
- 대화·이력 관련 화면

### 5단계 — 보호자·어르신 데이터
- 어르신 CRUD/검색/건강상태 API
- 보호자 홈, 목록·상세·계정 화면

### 6단계 — 알림·통화
- 통화 이력 API 및 화면
- FCM 토큰 등록/테스트
- WebSocket 채팅 구성

### 7단계 — 마무리
- 통합 시연 시나리오 점검
- README 및 docs(기획/아키텍처/ADR/WBS/SETUP) 작성
- GitHub 정리 및 발표 자료 연계

## 일정 관리 방식

백엔드/프론트 디렉터리를 분리해 병렬 개발하고,
API 계약(엔드포인트·DTO)을 맞춘 뒤 화면 연동하는 방식으로 진행했다.
