# 3.10.5 Unemployment Rate (LUR) 분석

IMF WEO `WEOApr2024.xlsx`의 지표 코드 `LUR`(실업률)을 사용합니다.

## VS Code에서 실행 (노트북)

1. VS Code에서 `lur_analysis/3.10.5_LUR_실업률_분석.ipynb` 열기
2. 커널을 Python 선택
3. 위쪽 **Run All** 또는 셀마다 `Shift+Enter`

`WEOApr2024.xlsx`는 노트북과 같은 폴더에 있어야 합니다.

## 분석 내용

- 2022년 실업률 오름차순 80개국
- 관심 국가: Korea, USA, Japan, Germany
- 같은 그래프에 `2023 - 2022` 차이값 표시
